## 12. Personal oil collection (new)

This is the big new "why sign up" feature. Track which oils you actually own, then the blend builder can recommend recipes from your own stash, and recipes you read will tell you which oils you'd still need to buy.

### Adding to your collection

- [ ] Signed in, open any oil page (e.g. `/oils/<click any oil card>`)
- [ ] Right side of the page header: a button labelled **+ Add to my collection**
- [ ] Click it → button changes to **🛒 In my collection — view**
- [ ] Reload the page → button still says it's in your collection (it stuck)
- [ ] Click the button again → **takes you to your collection page**, scrolled to that oil with its edit form already open. (Earlier this used to remove the oil on click, which was too easy to do by accident. To remove, you now have to go to the collection page explicitly.)
- [ ] Sign out → button now reads **Sign in to track** and goes to the login page

### `/my-collection` page

- [ ] Click the avatar (top-right) → **My Collection** in the dropdown
- [ ] If your collection is empty: friendly empty state with a link to the oil library
- [ ] Add 4–5 oils via the oil pages, then come back → see them listed with a stats strip at the top (total oils, total spend, expiring soon, library coverage)
- [ ] **Filter chips**: All / Carriers / Essentials — the count updates as you switch
- [ ] **Search box**: type part of an oil name → only matching rows show
- [ ] Click **Edit** on any row → form expands with these fields:
  - Quantity remaining (ml)
  - **Bottle size (ml)** — how big the bottle you bought is
  - **Price paid** — labelled with your currency (£, €, $, etc.). Change your currency in **Account → Profile** to see this update.
  - Opened on (date picker)
  - Expires on (date picker — leave blank for carriers and we'll compute from "opened on + shelf life" automatically)
  - Supplier
  - Batch number
  - Notes
- [ ] Row summary text shows price + size together when both filled in: e.g. "£12.50 for 30 ml". With only price, just the price. With only size, "30 ml bottle".

### Currency

- [ ] Go to **Account → Profile** → there's a new **Currency** dropdown
- [ ] Switch to your local currency (e.g. Euro if you're in Belgium, USD if US) → click Save profile
- [ ] The dropdown should still show the currency you picked (it should NOT jump back to the previous one — that was an earlier bug, now fixed)
- [ ] Go back to **My Collection** → all costs now display with the new currency symbol — but the numbers are unchanged. So if you had "£12.50" before, switching to EUR makes it "€12.50", not converting. **Re-enter prices in your new currency if needed.**
- [ ] The edit form's Price paid label updates to show the new currency code too
- [ ] Fill some fields → click **Save changes** → form closes; values persist on reload
- [ ] Click **Edit** again on the same row → values are still there

### Expiry warnings

- [ ] For a **carrier** oil: edit its row, set **Opened on** to a date about a year or two ago (depends on the oil's shelf life — try 18 months for Sweet Almond which has a ~12-month shelf life). Save.
- [ ] The row should now show an amber **⏳ Nd to expiry** or red **⚠ Expired** badge in the corner
- [ ] Set **Expires on** explicitly to yesterday → row turns red, **⚠ Expired** badge
- [ ] Top-of-page **Expiring soon** stat increments

### "From my collection" filter in the blend builder

This is the feature that gives the collection real teeth — build blends only from what you actually own.

- [ ] Go to **Build a Blend**, Tab 1 (Carriers)
- [ ] Top-right of the picker: a chip labelled **From my collection** appears (only when you have at least one carrier in your collection)
- [ ] Click it → only your collection carriers are listed; chip turns amber to show it's active
- [ ] Click it again → reverts to the full library
- [ ] Tab 2 (Essential Oils): same chip, scoped to your EOs
- [ ] If you have no carriers in your collection, the carriers chip doesn't appear; same for EOs
- [ ] Sign out → chip never appears

### Shopping list on a saved blend

- [ ] Save a blend that uses a mix of oils you own and oils you don't
- [ ] Open the blend's recipe page → right-column **Shopping list** card appears, listing the oils you still need
- [ ] Each missing oil has a **Buy ↗** link (if we have a buy link for it) that opens in a new tab
- [ ] Footer text says e.g. "You already have 2 of 3 oils in this recipe"
- [ ] Add one of the missing oils to your collection → reload the recipe page → it disappears from the shopping list
- [ ] When you own everything, the card is replaced by a green ✓ "You have every oil in this blend in your collection"
- [ ] Sign out and reload → the shopping list card disappears entirely (it's a signed-in-only feature)

### Mobile

- [ ] On a phone (or narrow window): hamburger menu → **My Collection** appears below My Blends
- [ ] `/my-collection` cards stack cleanly; the edit form fields don't overflow
- [ ] The Add-to-collection button on `/oils/[id]` is reachable without horizontal scroll
